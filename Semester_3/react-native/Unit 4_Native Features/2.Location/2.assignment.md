
# Assignment 1 - My Location Dashboard

## Objective

Build a React Native application using **Expo Location (`expo-location`)** that requests the user's location permission and displays their current location, last known location, and readable address.

---

## Requirements

### 1. Request Location Permission

Create a button:

```
Request Permission
```

Requirements:

- Ask for Foreground Location Permission.
- If permission is denied, show an alert.
- Do not continue until permission is granted.

---

### 2. Current Location

Create a button:

```
Get Current Location
```

Display:

- Latitude
- Longitude
- Accuracy
- Altitude
- Heading
- Speed
- Timestamp

---

### 3. Last Known Location

Create another button:

```
Get Last Known Location
```

Display:

- Latitude
- Longitude
- Accuracy

If no cached location exists, display:

```
No Last Known Location Found
```

---

### 4. Current Address

Convert the current coordinates into a readable address using Reverse Geocoding.

Display:

- Name
- Street
- City
- District
- State
- Country
- Postal Code

---

### 5. UI Requirements

The application should include:

- ScrollView
- Clean Layout
- Proper Spacing
- Cards for each section
- Loading Indicator while fetching data

---

## Bonus

Add a button:

```
Refresh Location
```

that reloads the current location.

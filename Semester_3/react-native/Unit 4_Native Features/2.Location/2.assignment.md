# Assignment 1 - My Location Dashboard

## Objective

Build a React Native application using **Expo Location (`expo-location`)** and **React Native Maps (`react-native-maps`)** that allows users to request location permission, retrieve their current location, fetch the last known location, search any place, display an interactive map, and show a human-readable address using Reverse Geocoding.

---

# Requirements

## Part 1 – Request Location Permission

Create a button:

```text
Request Permission
```

### Requirements

- Request **Foreground Location Permission**.
- If permission is denied:
  - Show an Alert.
  - Do not allow any location-related operations.
- If permission is granted:
  - Show a success alert.
  - Enable all location features.

---

## Part 2 – Get Current Location

Create a button:

```text
Get Current Location
```

### Requirements

When clicked:

- Fetch the user's current location.
- Save the location in state.
- Display:
  - Latitude
  - Longitude
  - Accuracy
  - Altitude
  - Heading
  - Speed
  - Timestamp
- Move the map camera to the current location.
- Place a marker on the map.
- Fetch the readable address using Reverse Geocoding.

---

## Part 3 – Get Last Known Location

Create a button:

```text
Get Last Known Location
```

### Requirements

- Retrieve the device's last known location.
- Display:
  - Latitude
  - Longitude
  - Accuracy
- If no previous location exists, display:

```text
No Last Known Location Found
```

---

## Part 4 – Refresh Current Location

Create a button:

```text
Refresh Location
```

### Requirements

- Fetch the latest current location.
- Update:
  - Current Location Card
  - Address
  - Marker Position
  - Map Camera

---

## Part 5 – Search Any Location

Create:

- A `TextInput`
- A button:

```text
Search Location
```

### Requirements

Allow users to search locations such as:

```text
Patna
Delhi
Mumbai
Goa
India Gate
Taj Mahal
```

When the user searches:

- Convert the place name into coordinates using Geocoding.
- Move the map to the searched location.
- Place a marker on the map.
- Display the readable address.

If the location is invalid:

- Show an Alert.

---

## Part 6 – Interactive Map

Display an interactive map.

### Requirements

- Show a default region when the app loads.
- Display the user's current location.
- Display the "My Location" button.
- Show a marker for the selected location.
- Animate the map whenever:
  - Current location changes.
  - A searched location is found.

---

## Part 7 – Current Address

Display a card containing:

- Name
- Street
- City
- District
- State
- Country
- Postal Code

If no address is available, display:

```text
No Address Available
```

---

## Part 8 – Loading Indicator

Whenever the application is:

- Fetching current location
- Fetching last known location
- Searching a location

Display an `ActivityIndicator`.

Hide it once the operation completes.

---

# Validation

Your application should handle the following cases:

- User cannot fetch location without permission.
- User cannot search an empty location.
- Display proper alerts for invalid actions.
- Handle all asynchronous errors using `try...catch`.

---

# UI Requirements

Your application should contain:

- ScrollView
- Buttons
- TextInput
- Cards
- Interactive Map
- Marker
- ActivityIndicator

Students are free to design the UI in their own way.

# Complete Code

Below is the complete code for this assignment.


```jsx

import { useRef, useState } from "react";
import {
  View,
  Text,
  ScrollView,
  Button,
  ActivityIndicator,
  Alert,
  TextInput,
  StyleSheet,
} from "react-native";

import MapView, { Marker } from "react-native-maps";
import * as Location from "expo-location";

export default function App() {

  // States
  const [permissionGranted, setPermissionGranted] = useState(false);

  const [currentLocation, setCurrentLocation] = useState(null);

  const [lastKnownLocation, setLastKnownLocation] =
    useState(null);

  const [address, setAddress] = useState(null);

  const [loading, setLoading] = useState(false);

  const [search, setSearch] = useState("");

  const [marker, setMarker] = useState(null);

  // Map Reference

  const mapRef = useRef(null);

  // Request Foreground Permission

  const requestPermission = async () => {
    try {
      const { granted } =
        await Location.requestForegroundPermissionsAsync();

      if (!granted) {
        Alert.alert(
          "Permission Denied",
          "Location permission is required to continue."
        );

        setPermissionGranted(false);
        return;
      }

      setPermissionGranted(true);

      Alert.alert(
        "Success",
        "Location Permission Granted"
      );
    } catch (error) {
      Alert.alert("Error", error.message);
    }
  };

  // Get Current Location

  const getCurrentLocation = async () => {
    if (!permissionGranted) {
      Alert.alert(
        "Permission Required",
        "Please request location permission first."
      );
      return;
    }

    try {
      setLoading(true);

      const location =
        await Location.getCurrentPositionAsync({
          accuracy: Location.Accuracy.High,
        });

      // Save Current Location
      setCurrentLocation(location);

      // Update Marker Position
      setMarker({
        latitude: location.coords.latitude,
        longitude: location.coords.longitude,
      });

      // Move Map Camera
      mapRef.current?.animateToRegion(
        {
          latitude: location.coords.latitude,
          longitude: location.coords.longitude,
          latitudeDelta: 0.01,
          longitudeDelta: 0.01,
        },
        1000
      );

      // Fetch Address
      await getAddress(
        location.coords.latitude,
        location.coords.longitude
      );
    } catch (error) {
      Alert.alert("Error", error.message);
    } finally {
      setLoading(false);
    }
  };

  // Get Last Known Location

  const getLastKnownLocation = async () => {
    if (!permissionGranted) {
      Alert.alert(
        "Permission Required",
        "Please request permission first."
      );
      return;
    }

    try {
      setLoading(true);

      const location =
        await Location.getLastKnownPositionAsync();

      if (!location) {
        Alert.alert(
          "No Last Known Location Found"
        );

        setLastKnownLocation(null);
        return;
      }

      setLastKnownLocation(location);
    } catch (error) {
      Alert.alert("Error", error.message);
    } finally {
      setLoading(false);
    }
  };

  // Reverse Geocoding
  // Converts Latitude & Longitude into Human Readable Address

  const getAddress = async (
    latitude,
    longitude
  ) => {
    try {
      const result =
        await Location.reverseGeocodeAsync({
          latitude,
          longitude,
        });

      if (result.length > 0) {
        setAddress(result[0]);
      }
    } catch (error) {
      Alert.alert("Error", error.message);
    }
  };

  // Search Any Place
  // Uses Geocoding

  const searchLocation = async () => {
    if (!search.trim()) {
      Alert.alert(
        "Validation",
        "Please enter a location."
      );
      return;
    }

    try {
      setLoading(true);

      const result =
        await Location.geocodeAsync(search);

      if (result.length === 0) {
        Alert.alert(
          "Location Not Found"
        );
        return;
      }

      const { latitude, longitude } =
        result[0];

      // Update Marker
      setMarker({
        latitude,
        longitude,
      });

      // Move Map
      mapRef.current?.animateToRegion(
        {
          latitude,
          longitude,
          latitudeDelta: 0.01,
          longitudeDelta: 0.01,
        },
        1000
      );

      // Update Address
      await getAddress(latitude, longitude);
    } catch (error) {
      Alert.alert("Error", error.message);
    } finally {
      setLoading(false);
    }
  };

  // Refresh Current Location

  const refreshLocation = async () => {
    await getCurrentLocation();
  };

  return (
        <ScrollView
      style={styles.container}
      contentContainerStyle={styles.content}
      showsVerticalScrollIndicator={false}
    >
      {/* ==============================
          App Title
      ============================== */}

      <Text style={styles.heading}>
        My Location Dashboard
      </Text>

      {/* ==============================
          Loading Indicator
      ============================== */}

      {loading && (
        <ActivityIndicator
          size="large"
          color="#00695C"
          style={styles.loader}
        />
      )}

      {/* ==============================
          Action Buttons
      ============================== */}

      <View style={styles.buttonContainer}>
        <Button
          title="Request Permission"
          onPress={requestPermission}
        />
      </View>

      <View style={styles.buttonContainer}>
        <Button
          title="Get Current Location"
          onPress={getCurrentLocation}
        />
      </View>

      <View style={styles.buttonContainer}>
        <Button
          title="Get Last Known Location"
          onPress={getLastKnownLocation}
        />
      </View>

      <View style={styles.buttonContainer}>
        <Button
          title="Refresh Location"
          onPress={refreshLocation}
        />
      </View>

      {/* ==============================
          Search Location
      ============================== */}

      <View style={styles.card}>
        <Text style={styles.cardTitle}>
          Search Any Location
        </Text>

        <TextInput
          value={search}
          onChangeText={setSearch}
          placeholder="Enter city, place, landmark..."
          style={styles.input}
        />

        <Button
          title="Search Location"
          onPress={searchLocation}
        />
      </View>

      {/* ==============================
          Interactive Map
      ============================== */}

      <View style={styles.card}>
        <Text style={styles.cardTitle}>
          Interactive Map
        </Text>

        <MapView
          ref={mapRef}
          style={styles.map}
          initialRegion={{
            latitude: 28.6139,
            longitude: 77.209,
            latitudeDelta: 10,
            longitudeDelta: 10,
          }}
          showsUserLocation
          showsMyLocationButton
        >
          {marker && (
            <Marker
              coordinate={marker}
              title="Selected Location"
            />
          )}
        </MapView>
      </View>

      {/* ==============================
          Current Location Card
      ============================== */}

      <View style={styles.card}>
        <Text style={styles.cardTitle}>
          Current Location
        </Text>

        {currentLocation ? (
          <>
            <Text style={styles.text}>
              Latitude:
              {currentLocation.coords.latitude}
            </Text>

            <Text style={styles.text}>
              Longitude:
              {currentLocation.coords.longitude}
            </Text>

            <Text style={styles.text}>
              Accuracy:
              {currentLocation.coords.accuracy}
            </Text>

            <Text style={styles.text}>
              Altitude:
              {currentLocation.coords.altitude ?? "N/A"}
            </Text>

            <Text style={styles.text}>
              Heading:
              {currentLocation.coords.heading ?? "N/A"}
            </Text>

            <Text style={styles.text}>
              Speed:
              {currentLocation.coords.speed ?? "N/A"}
            </Text>

            <Text style={styles.text}>
              Timestamp:
              {new Date(
                currentLocation.timestamp
              ).toLocaleString()}
            </Text>
          </>
        ) : (
          <Text style={styles.noData}>
            No Current Location Available
          </Text>
        )}
      </View>
            {/* ==============================
          Last Known Location
      ============================== */}

      <View style={styles.card}>
        <Text style={styles.cardTitle}>
          Last Known Location
        </Text>

        {lastKnownLocation ? (
          <>
            <Text style={styles.text}>
              Latitude: {lastKnownLocation.coords.latitude}
            </Text>

            <Text style={styles.text}>
              Longitude: {lastKnownLocation.coords.longitude}
            </Text>

            <Text style={styles.text}>
              Accuracy: {lastKnownLocation.coords.accuracy}
            </Text>
          </>
        ) : (
          <Text style={styles.noData}>
            No Last Known Location Found
          </Text>
        )}
      </View>

      {/* ==============================
          Current Address
      ============================== */}

      <View style={styles.card}>
        <Text style={styles.cardTitle}>
          Current Address
        </Text>

        {address ? (
          <>
            <Text style={styles.text}>
              Name: {address.name || "N/A"}
            </Text>

            <Text style={styles.text}>
              Street: {address.street || "N/A"}
            </Text>

            <Text style={styles.text}>
              City: {address.city || "N/A"}
            </Text>

            <Text style={styles.text}>
              District: {address.district || "N/A"}
            </Text>

            <Text style={styles.text}>
              State: {address.region || "N/A"}
            </Text>

            <Text style={styles.text}>
              Country: {address.country || "N/A"}
            </Text>

            <Text style={styles.text}>
              Postal Code: {address.postalCode || "N/A"}
            </Text>
          </>
        ) : (
          <Text style={styles.noData}>
            No Address Available
          </Text>
        )}
      </View>

      <View style={{ height: 30 }} />
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: "#E0F2F1",
  },

  content: {
    padding: 20,
    paddingTop: 50,
    paddingBottom: 40,
  },

  heading: {
    fontSize: 28,
    fontWeight: "bold",
    textAlign: "center",
    color: "#004D40",
    marginBottom: 25,
  },

  loader: {
    marginBottom: 20,
  },

  buttonContainer: {
    marginBottom: 12,
  },

  card: {
    backgroundColor: "#FFFFFF",
    borderRadius: 12,

    shadowColor: "#000",
    shadowOpacity: 0.1,
    shadowRadius: 6,

      width: 0,
      height: 2,
    },
    elevation: 3,
  },

  cardTitle: {
    fontSize: 20,
    fontWeight: "bold",
    marginBottom: 12,
    color: "#00695C",
  },

  input: {
    borderWidth: 1,
    borderColor: "#BDBDBD",

  },

  map: {
    width: "100%",

    borderRadius: 10,
  },

  text: {
    fontSize: 16,
    color: "#333",
    marginBottom: 8,
  },

  noData: {
    fontSize: 16,
    color: "gray",
    fontStyle: "italic",
  },
});
```

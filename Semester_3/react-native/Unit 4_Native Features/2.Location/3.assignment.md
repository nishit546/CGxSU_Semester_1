# Assignment 2 - Geo Location Manager

## Objective

Build a React Native application using **Expo Location (`expo-location`)** and **React Native Maps (`react-native-maps`)** that allows users to:

* Search for any location in the world without requiring location permission.
* View searched locations on an interactive map.
* Request location permission only when accessing the device's current location.
* Display the user's current location, last known location, and a human-readable address.

---

# Features

## 1. Search Any Location (No Permission Required)

When the application opens:

* Display an interactive map centered on a default location.
* Do **not** ask for location permission immediately.
* Allow users to search for any place in the world.

Create:

```
Search Box
```

Requirements:

* Search by place name.
* Use `Location.geocodeAsync()`.
* Move the map to the searched location.
* Update the map marker.
* Display the readable address using Reverse Geocoding.
* This feature should work **without requesting location permission**.

Example Searches:

```
New Delhi
Mumbai
London
Paris
Tokyo
Eiffel Tower
Statue of Liberty
Taj Mahal
```

---

## 2. Request Location Permission

Create a button:

```
Request Permission
```

Requirements:

* Request Foreground Location Permission.
* Show an alert if permission is denied.
* Store the permission status.
* This button is optional because the app should also request permission automatically whenever the user tries to access their current location.

---

## 3. Get Current Location

Create a button:

```
Get Current Location
```

Requirements:

If permission has not been granted:

* Request Foreground Location Permission automatically.
* If denied, stop execution.

If permission is granted:

Display:

* Latitude
* Longitude
* Accuracy
* Altitude
* Heading
* Speed
* Timestamp

Also:

* Move the map to the user's current location.
* Update the marker.
* Display the current readable address.

---

## 4. Last Known Location

Create another button:

```
Get Last Known Location
```

Requirements:

If permission has not been granted:

* Request permission first.

Display:

* Latitude
* Longitude
* Accuracy

If no cached location exists:

```
No Last Known Location Found
```

---

## 5. Current Address

Whenever the marker changes because of:

* Current Location
* Refresh Location
* Search Location

Convert its coordinates into a readable address using Reverse Geocoding.

Display:

* Name
* Street
* City
* District
* State
* Country
* Postal Code

---

## 6. Interactive Map

Implement **React Native Maps**.

Requirements:

* Display an interactive map.
* Initially load a default region.
* Show a marker.
* Animate the camera whenever the marker changes.
* The marker should move when:

  * User searches a location.
  * User gets current location.
  * User refreshes location.

---

## 7. Refresh Location

Create a button:

```
Refresh Location
```

Requirements:

* Reload the user's current location.
* Update the marker.
* Animate the map.
* Refresh the address.

---

## 8. UI Requirements

The application should include:

* ScrollView
* Clean Layout
* Cards
* ActivityIndicator while loading
* Search Box
* Interactive Map
* Map Marker

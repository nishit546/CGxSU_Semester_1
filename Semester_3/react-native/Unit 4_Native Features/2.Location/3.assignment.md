# Assignment 2 - Live Location Tracker

## Objective

Build a React Native application using **Expo Location (`expo-location`)** that continuously tracks the user's location, automatically updates the address, and provides tracking statistics.

---

## Requirements

### 1. Request Permission

Ask for Foreground Location Permission before starting tracking.

If permission is denied:

- Show an alert.
- Do not start tracking.

---

### 2. Start Tracking

Create a button:

```
Start Tracking
```

Use:

```
watchPositionAsync()
```

Display live:

- Latitude
- Longitude
- Accuracy
- Speed
- Heading
- Timestamp

The values should update automatically whenever the location changes.

---

### 3. Stop Tracking

Create a button:

```
Stop Tracking
```

Requirements:

- Stop the subscription.
- Prevent memory leaks.
- Show:

```
Tracking Stopped
```

---

### 4. Live Address

Whenever the location changes:

Automatically display:

- Name
- Street
- City
- State
- Country
- Postal Code

No extra button should be required.

---

### 5. Accuracy Selector

Provide an option to change the tracking accuracy.

Supported options:

- Low
- Balanced
- High

Changing the accuracy should affect future tracking updates.

---

### 6. Tracking Statistics

Display:

- Tracking Status
- Total Updates Received
- Current Accuracy Level

Example:

```
Tracking Status : Tracking

Updates Received : 15

Accuracy : High
```

---

### 7. Reset

Create a button:

```
Reset
```

The button should:

- Stop Tracking
- Remove Subscription
- Clear Location
- Clear Address
- Reset Update Counter

---

## UI Requirements

The application should include:

- Header
- Status Card
- Live Location Card
- Address Card
- Statistics Card
- Accuracy Selector
- Action Buttons

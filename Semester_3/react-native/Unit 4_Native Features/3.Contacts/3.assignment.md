
# Assignment 2 - Smart Contact Manager

## Objective

Build a professional Contact Management application using **`expo-contacts`** that allows users to search, edit, delete, export, and manage contacts.

---

## Requirements

### Part 1 - Request Permission

- Request Contacts Permission.
- Handle denied permission properly.

---

### Part 2 - Load Contacts

Fetch contacts using:

```js
Contacts.getContactsAsync()
```

Request these fields:

```js
Contacts.Fields.Name
Contacts.Fields.PhoneNumbers
Contacts.Fields.Emails
Contacts.Fields.Image
Contacts.Fields.Company
Contacts.Fields.JobTitle
```

Sort contacts using:

```js
Contacts.SortTypes.UserDefault
```

---

### Part 3 - Display Contact Cards

Each contact card should display:

- Profile Image / Avatar
- Full Name
- Company
- Job Title
- First Phone Number
- First Email Address

---

### Part 4 - Search Contacts

Implement a search bar.

Search by:

- Name
- Phone Number
- Email Address

The search should update instantly while typing.

---

### Part 5 - Add New Contact

Create a Floating Action Button.

Example:

```text
+
```

When pressed,

Open the native contact form using:

```js
Contacts.presentFormAsync(null)
```

Refresh the contacts list after saving.

---

### Part 6 - Edit Contact

Each contact card should contain an:

```text
Edit
```

button.

Open the native editor using:

```js
Contacts.presentFormAsync(contact.id)
```

Refresh the list after editing.

---

### Part 7 - Delete Contact

Each contact card should contain a:

```text
Delete
```

button.

Requirements:

- Show confirmation dialog.
- Delete using:

```js
Contacts.removeContactAsync(contact.id)
```

Refresh the contacts after deletion.

---

### Part 8 - Export Contact

Each contact card should contain an:

```text
Export
```

button.

Export the selected contact using:

```js
Contacts.writeContactToFileAsync(contact.id)
```

Display the exported file URI using:

- Alert
- Console

---

### Part 9 - Contact Statistics

Display statistics at the top.

Example:

```text
Total Contacts : 152

Contacts With Phone : 140

Contacts With Email : 86

Contacts Without Phone : 12
```

---

### Part 10 - Pull To Refresh

Implement:

```jsx
RefreshControl
```

inside the `FlatList`.

Users should be able to refresh contacts by pulling down.

---

### Part 11 - Empty State

If no contacts exist, display:

```text
No Contacts Available

Tap + to add your first contact.
```

---

### Part 12 - Bonus Challenge (Optional)

Implement one or more of the following:

- Filter contacts with phone numbers only.
- Filter contacts with email addresses only.
- Display contacts grouped alphabetically (A–Z).
- Show all phone numbers for a contact.
- Show all email addresses for a contact.
- Display contact company and job title in different colors.
- Add a "View Details" screen using React Navigation.

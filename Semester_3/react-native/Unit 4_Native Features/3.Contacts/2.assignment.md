
# Assignment 1 - Contact Explorer

## Objective

Build a React Native application using **`expo-contacts`** that requests contact permission, loads all contacts, displays them in a professional list, and provides real-time search functionality.

---

## Requirements

### Part 1 - Request Contact Permission

Create a button:

```text
Request Permission
```

Requirements:

- Request Contacts Permission.
- If permission is denied, show an alert.
- Do not continue until permission is granted.

---

### Part 2 - Load Contacts

Create a button:

```text
Load Contacts
```

Requirements:

- Fetch contacts using:

```js
Contacts.getContactsAsync()
```

Request the following fields:

```js
Contacts.Fields.Name
Contacts.Fields.PhoneNumbers
Contacts.Fields.Emails
Contacts.Fields.Image
```

Sort contacts using:

```js
Contacts.SortTypes.FirstName
```

---

### Part 3 - Display Contacts

Display contacts using:

```jsx
FlatList
```

Each contact card should display:

- Profile Image (if available)
- Avatar (first letter if image is unavailable)
- Full Name
- First Phone Number
- First Email Address (if available)

---

### Part 4 - Loading State

While contacts are loading, display:

```text
Loading Contacts...
```

---

### Part 5 - Empty State

If no contacts exist, display:

```text
No Contacts Found
```

---

### Part 6 - Search Contacts

Add a search bar.

Requirements:

- Search by Name.
- Search should be case-insensitive.
- Update results in real-time.
- If no contact matches, show:

```text
No Contacts Found
```

---

### Part 7 - Contact Count

Display the total number of contacts.

Example:

```text
Total Contacts : 143
```

---

### Part 8 - Refresh Contacts

Create a button:

```text
Refresh
```

Reload the contacts list.

# Assignment 1 - Contact Explorer

This assignment is based on the concepts covered in the **`expo-contacts`** module.

---

## Objective

Create a React Native application that works with the device's native contacts.

Your application should allow users to:

- Request contact permission
- Get contact data
- Sort contacts by First Name or Last Name
- Search contacts by Name or Phone Number
- Display contact images or avatars
- Add new contacts
- Delete contacts
- Make phone calls
- Refresh the contact list
- Handle loading, empty, and error states

---

# Requirements

## 1. Contact Permission

Request permission before accessing contacts.

Use:

```js
Contacts.requestPermissionsAsync()
```

### Requirements

- Request Contacts permission.
- Check whether permission is granted.
- If permission is denied, show an `Alert`.
- Do not access contacts without permission.
- Handle errors properly.

---

# 2. Get Contact Data

After permission is granted, get contacts from the device.

Use:

```js
Contacts.getContactsAsync()
```

Store the contacts in React state.

---

# 3. Sort Contacts

The user should be able to sort contacts using:

```js
Contacts.SortTypes.FirstName
```

and:

```js
Contacts.SortTypes.LastName
```

Provide two options:

```text
First Name
Last Name
```

### Expected Behavior

Selecting **First Name** should sort contacts according to their first name.

Selecting **Last Name** should sort contacts according to their last name.

---

# 4. Display Contacts

Use:

```jsx
FlatList
```

to display the contacts.

Each contact card should display:

- Profile image if available
- Avatar if image is unavailable
- Full name
- First phone number
- First email address if available
- Delete button
- Phone/Call icon

Use the contact's unique ID as the `FlatList` key.

---

# 5. Profile Image / Avatar

If the contact has an image, display it.

If the contact does not have an image, display an avatar using the first letter of the contact's name.

Example:

```text
Rajesh Ranjan
      ↓
      R
```

Make sure the application does not crash if:

- Contact has no image
- Contact has no name

---

# 6. Search Contacts

Add a search bar.

Example:

```text
Search by name or phone number...
```

Search must work in **real time**.

Use:

```jsx
<TextInput />
```

and update the search value using:

```js
onChangeText
```

---

## Search by Name

Users should be able to search contacts by name.

Example:

```text
Search: Rahul
```

Possible results:

```text
Rahul Sharma
Rahul Kumar
Rahul Verma
```

Search must be **case-insensitive**.

For example:

```text
rahul
```

should also find:

```text
Rahul Sharma
```

---

## Search by Phone Number

Users should also be able to search using a phone number.

Example:

```text
Search: 9876
```

This should find contacts whose phone number contains:

```text
9876
```

The final search should support:

```text
Name OR Phone Number
```

---

# 7. No Search Results

If no contact matches the search, display:

```text
No Contacts Found
```

This should update automatically while the user types.

---

# 8. Contact Count

Display the total number of contacts.

Example:

```text
Total Contacts : 143
```

The count should update after:

- Adding a contact
- Deleting a contact
- Refreshing contacts

---

# 9. Loading State

While contacts are loading, display:

```text
Loading Contacts...
```

The loading state should be shown during:

- Initial contact loading
- Refreshing contacts

---

# 10. Add Contact

Create an:

```text
Add Contact
```

button.

The user should be able to add a new contact containing at least:

- First Name
- Last Name
- Phone Number
- Email

---

## Use `addContactAsync()`

Try to add the contact using:

```js
Contacts.addContactAsync()
```

The contact should be created using a Contact Object.

---

## Fallback: `presentFormAsync()`

If `addContactAsync()` does not work on the device, use:

```js
Contacts.presentFormAsync()
```

to open the native Contacts form.

After the contact is successfully added, refresh the contact list.

---

# 11. Refresh Contacts

Create a:

```text
Refresh
```

button.

When the user presses Refresh:

- Reload contacts from the device.
- Update the contact list.
- Update the contact count.
- Apply the selected sorting.
- Keep the current application state consistent.

Try to reuse your existing contact-loading function instead of duplicating code.

---

# 12. Delete Contact

Every contact card should have a:

```text
Delete
```

button.

Use:

```js
Contacts.removeContactAsync()
```

The selected contact's unique:

```js
contact.id
```

should be used for deletion.

---

## Delete Confirmation

Do not delete a contact immediately.

Show a confirmation alert first.

Example:

```text
Delete Contact

Are you sure you want to delete
Rajesh Ranjan?

Cancel        Delete
```

The Delete option should be a destructive action.

After deletion:

- Update the contact list.
- Update the contact count.
- Keep the UI synchronized with the device contacts.

---

# 13. Phone / Call Icon

Beside the Delete button, add a phone/call icon.

Example:

```text
Delete    📞
```

You may use:

```js
Ionicons
```

or another icon library available in your project.

---

# 14. Make a Phone Call

When the user taps the phone icon, open the device's phone application.

Use React Native:

```js
Linking
```

Use the:

```text
tel:
```

URL scheme.

pressing the call icon should open the phone application for that number.

---

## Contact Without Phone Number

Some contacts may not have a phone number.

If the user presses the call icon for such a contact, show:

```text
No Phone Number

This contact does not have a phone number.
```

Do not attempt to open an invalid `tel:` URL.

---

# 15. Error Handling

Use `try...catch` for asynchronous operations.

Handle errors for:

- Requesting permission
- Loading contacts
- Adding contacts
- Opening the native contact form
- Deleting contacts
- Making phone calls

Display meaningful error messages using `Alert`.

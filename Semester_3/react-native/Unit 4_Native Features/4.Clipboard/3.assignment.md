# Assignment 2 - Contact Clipboard Manager

This assignment is based on the concepts covered in the **`expo-contacts`** and **`expo-clipboard`** modules.

---

# Objective

Create a React Native application that allows users to:

- Request contact permission
- Load device contacts
- Display contact names and phone numbers
- Search contacts by name or phone number
- Sort contacts by First Name or Last Name
- Display contact avatars
- Copy a contact's phone number
- Copy a contact's email
- Copy complete contact information
- Paste text from the Clipboard
- Detect Clipboard changes
- Detect Clipboard content type
- Paste an image from the Clipboard
- Display image dimensions
- Add a new contact
- Delete a contact
- Properly clean up Clipboard listeners

---

# 1. Installation

Install both packages:

```bash
npx expo install expo-contacts expo-clipboard
```

---

# 2. Contact Permission

When the user presses:

```text
[ Load Contacts ]
```

request contact permission using:

```js
Contacts.requestPermissionsAsync()
```

If permission is denied, display:

```text
Contact permission is required.
```

If permission is granted, load the contacts.

---

# 3. Load Contacts

Use:

```js
Contacts.getContactsAsync()
```

Request the following fields:

```js
Contacts.Fields.Name
Contacts.Fields.PhoneNumbers
Contacts.Fields.Emails
Contacts.Fields.Image
```

Example:

```js
const { data } =
  await Contacts.getContactsAsync({
    fields: [
      Contacts.Fields.Name,
      Contacts.Fields.PhoneNumbers,
      Contacts.Fields.Emails,
      Contacts.Fields.Image,
    ],
  });
```

Store the contacts using `useState`.

# 12. Clipboard Change Listener

When the application is open, listen for Clipboard changes.

Use:

```js
Clipboard.addClipboardListener()
```

Example:

```js
useEffect(() => {

  const subscription =
    Clipboard.addClipboardListener(
      (event) => {

        // Detect content type

      }
    );

  return () => {

    subscription.remove();

  };

}, []);
```

# 18. Contact ID

When deleting a contact, use:

```js
contact.id
```

Do not use the contact name as the identifier.

Example:

```js
const deleteContact = async (id) => {

  await Contacts.removeContactAsync(id);

};
```

The important concept is:

```text
item.id

↓

send ID

↓

receive ID

↓

delete contact
```

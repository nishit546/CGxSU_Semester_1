
# Camera (`expo-camera`)

## What is `expo-camera`?

`expo-camera` is an Expo SDK module that allows your React Native application to access the device's built-in camera.

Using this package, you can:

* Open the camera preview
* Take photos
* Record videos
* Scan QR codes
* Scan Barcodes
* Control flash
* Switch between front and back camera
* Zoom camera
* Read camera permissions
* Pause or resume preview
* Capture high-quality images

Instead of writing native Android (Java/Kotlin) or iOS (Swift/Objective-C) code, Expo provides a JavaScript API that works on both platforms.

---

# Why do we need expo-camera?

Many real-world applications require camera functionality.

Examples include:

* Instagram
* Snapchat
* WhatsApp
* Google Lens
* QR Scanner Apps
* Banking Apps (Document Verification)
* Food Delivery Apps (Upload Proof)
* Face Verification Apps

Without `expo-camera`, your app cannot directly communicate with the device camera.

# 2. useCameraPermissions()

Before opening the camera, the app must ask the user for permission.

The `useCameraPermissions()` hook helps us:

* Check the current permission status.
* Request permission if needed.
* Know whether permission is granted or denied.

---

```jsx
import { useCameraPermissions } from "expo-camera";

export default function App() {
  const [permission, requestPermission] = useCameraPermissions();

```

### Explanation

```jsx

```

This hook returns two values:

* `permission` → Current camera permission status.
* `requestPermission()` → Function to ask the user for camera access.

### Explanation

# 2. `zoom`

The `zoom` prop controls **how much the camera is zoomed in or out**.

Zoom allows users to capture objects that are far away without physically moving closer.

Think of it like using the zoom feature in your phone's default Camera app.

---

# Zoom Range

The `zoom` value ranges from **0** to **1**.

```text
0 → No Zoom (Default)

1 → Maximum Zoom
```

Intermediate values provide different zoom levels.

```text

↓
0.2
↓
0.4
↓
0.6
↓
0.8
↓
1
```

# Zoom Using a Slider

Most camera apps allow users to zoom by dragging a slider.

> **Note:** `Slider` is **not part of `expo-camera`**. It comes from a separate package.

### Installation

```bash
npx expo install @react-native-community/slider
```

### Import

```jsx
import Slider from "@react-native-community/slider";
```

### Basic Example

```jsx
<Slider
  minimumValue={0}
  maximumValue={1}
  value={zoom}
  onValueChange={setZoom}
/>
```

### Explanation

* `minimumValue={0}` → Minimum zoom level.
* `maximumValue={1}` → Maximum zoom level.
* `value={zoom}` → Current zoom value.
* `onValueChange={setZoom}` → Updates the zoom whenever the slider moves.

---

# Complete Small Example

```jsx
import { useState } from "react";
import { View } from "react-native";
import { CameraView } from "expo-camera";
import Slider from "@react-native-community/slider";

export default function App() {
  const [zoom, setZoom] = useState(0);

  return (
    <View style={{ flex: 1 }}>
      <CameraView
        style={{ flex: 1 }}
        zoom={zoom}
      />

      <Slider
        minimumValue={0}
        maximumValue={1}
        value={zoom}
        onValueChange={setZoom}
      />
    </View>
  );
}
```

# Things to Remember

* `zoom` accepts values between **0** and **1**.
* `0` means **no zoom**.
* `1` means **maximum zoom**.

* The `zoom` prop is commonly controlled using **React State** and a **Slider**.

# Things to Remember

* `onBarcodeScanned` is called automatically when a supported barcode is detected.
* The callback receives information such as the barcode `type` and decoded `data`.
* QR codes and barcodes can contain URLs, text, phone numbers, Wi-Fi credentials, product IDs, and more.
* If you don't prevent repeated scans, the callback may be triggered multiple times while the barcode remains in view.

# Assignment 2 – Smart Camera Utility App

## Objective

Build a **Smart Camera Utility App** using **Expo Camera** that focuses on camera lifecycle management, multiple camera modes, media handling, gesture interactions, gallery integration, and overall user experience.

The application should simulate the behavior of a modern camera app by combining photo capture, video recording, QR/Barcode scanning, media preview, gallery saving, and session history.

---

# Requirements

---

# Part 1 – Camera Initialization & Permissions

## Requirements

- Request Camera Permission.
- Request Microphone Permission.
- Request Media Library Permission.
- Display a loading indicator while the camera initializes.
- Show **Camera Ready** after initialization.
- Prevent any camera action before initialization.

---

# Part 2 – Camera Modes

Implement three modes inside the same screen.

```text
Photo

Video

Scanner
```

## Requirements

Switching modes should update the camera behavior automatically.

### Photo Mode

```text
Capture Photo

Flash

Torch

Zoom

Picture Quality
```

### Video Mode

```text
Start Recording

Stop Recording

Recording Timer

Zoom
```

### Scanner Mode

```text
QR Scanner

Pause Scanner

Resume Scanner

Reset Scan
```

Only the controls relevant to the selected mode should be visible.

# Part 3 – Camera Controls

Implement

- Flip Camera
- Flash Toggle
- Torch Toggle
- Zoom Slider
- Pinch-to-Zoom Gesture

### Additional Requirements

- Disable Flash while using the Front Camera.
- Display an appropriate message explaining why Flash is unavailable.
- Torch should work only with the Back Camera.

# Part 5 – Preview Screen

Instead of immediately returning to the camera, display a preview screen.

Options

```text
Retake

Use Photo

Save to Gallery
```

### Retake

Return to the camera.

### Use Photo

Store the captured photo information inside memory (state).

### Save to Gallery

Save the captured image to the device gallery using **expo-media-library**.

For each captured photo display

# Part 10 – Camera Lifecycle

Handle the camera lifecycle correctly.

Requirements

- Pause Preview
- Resume Preview
- Disable Capture while preview is paused
- Disable Recording while preview is paused
- Resume Preview without restarting the camera

# Part 11 – Save Media to Gallery

Use **expo-media-library**.

Requirements

- Request Media Library Permission.
- Save captured photos to the device gallery.
- Save recorded videos to the device gallery.
- Display a success or failure message after saving.
- Show the Save button only after capture or recording.

# Part 14 – Error Handling

Handle all possible camera errors gracefully.

Requirements

- Camera Permission Denied
- Microphone Permission Denied
- Media Library Permission Denied
- Camera Not Ready

- Gallery Save Failure
- Scanner Errors

Display meaningful alerts instead of crashing the application.

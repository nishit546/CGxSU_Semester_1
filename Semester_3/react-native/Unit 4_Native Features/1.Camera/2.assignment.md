#  Assignment – Camera App using Expo Camera

##  Objective

Build a **fully functional Camera Application** using **Expo Camera** that demonstrates all the important features provided by the library.

The goal of this assignment is to understand how to work with camera permissions, capture photos and videos, scan QR codes, control camera settings, and manage camera state.

---

#  Requirements

Create a screen named **CameraScreen** that implements the following features.

---

## Part 1 – Camera Permission 

### Requirements

* Ask for camera permission when the screen loads.
* If permission is denied, display an appropriate message.
* Provide a button to request permission again.

### Expected Output

```
Camera permission is required.

[Grant Permission]
```

---

## Part 2 – Live Camera Preview 

### Requirements

* Display the live camera preview.
* Camera should occupy most of the screen.
* Camera should only render after permission has been granted.

---

## Part 3 – Flip Camera 

### Requirements

Add a button that switches between

* Front Camera
* Back Camera

Button Example

```
 Flip Camera
```

---

## Part 4 – Flash Toggle 

### Requirements

Allow users to switch between

* Flash Off
* Flash On
* Flash Auto

Display the currently selected flash mode.

Example

```
Flash : OFF
```

---

## Part 5 – Zoom Slider 

### Requirements

Add a zoom slider.

* Minimum Zoom → 0
* Maximum Zoom → 1

The camera should zoom smoothly as the slider moves.

---

## Part 6 – Pinch-to-Zoom 

### Requirements

Support pinch gesture for zooming.

Users should be able to zoom using two fingers just like Instagram or WhatsApp camera.

---

## Part 7 – Capture Photo 

### Requirements

Add a capture button.

When pressed

* Capture photo
* Display captured image URI
* Show success message

Example

```
Photo Captured!

file:///...
```

---

## Part 8 – Record Video 

### Requirements

Provide

* Start Recording button
* Stop Recording button

Display

```
Recording...
```

while recording.

After stopping

Display recorded video's URI.

---

## Part 9 – QR / Barcode Scanner

### Requirements

Detect

* QR Code
* Barcode

After scanning

Display

```
Scanned Value

https://expo.dev
```

Prevent duplicate scans until scanning is reset.

---

## Part 10 – Picture Quality 

Allow user to select image quality

```
High
Medium
Low
```

Apply the selected quality when capturing a photo.

---

## Part 11 – Base64 Output 

Capture photo with

```
base64: true
```

Display

* Base64 string length

Example

```
Base64 Length

1,245,332 Characters
```

---

## Part 12 – EXIF Metadata 

Capture image with

```
exif: true
```

Display at least

* Width
* Height
* Orientation
* Timestamp (if available)

---

## Part 13 – Camera Ready Event 

Use

```
onCameraReady
```

Display

```
Camera Ready 
```

when initialization is complete.

# Assignment – Camera App using Expo Camera

## Objective

Build a fully functional Camera Application using **Expo Camera** that demonstrates camera permissions, photo capture, video recording, barcode scanning, camera controls, media preview, gesture handling, and other advanced camera features.

The application provides a complete camera experience with support for images, videos, QR/Barcode scanning, zoom controls, flash modes, torch, picture quality selection, and media preview.

---

# Features Implemented

## Part 1 – Camera & Microphone Permissions

### Implemented

- Requests **Camera Permission** automatically when the screen loads.
- Requests **Microphone Permission** for video recording.
- Displays a permission required screen if camera access is denied.
- Allows requesting permission again.

### Output

```text
Camera permission is required.

[Grant Permission]
```

---

## Part 2 – Live Camera Preview

### Implemented

- Displays live camera preview.
- Camera is rendered only after permission is granted.
- Camera occupies the top section of the screen.

---

## Part 3 – Flip Camera

### Implemented

Switch between

- Front Camera
- Back Camera

Button

```text
Flip
```

---

## Part 4 – Flash Control

### Implemented

Cycles through

- Flash Off
- Flash On
- Flash Auto

Supported internally by Expo Camera.

---

## Part 5 – Torch Control

### Implemented

Separate button for

- Torch ON
- Torch OFF

Unlike Flash, Torch provides continuous flashlight while camera preview is active.

---

## Part 6 – Zoom Control

### Implemented

Two different zoom methods are supported.

### Slider Zoom

- Minimum = 0
- Maximum = 1

### Pinch to Zoom

Users can pinch directly on the camera preview to zoom smoothly using Gesture Handler and Reanimated.

---

## Part 7 – Capture Photo

### Implemented

Capture a photo using

```text
Capture Photo
```

Captured image includes

- Image URI
- Base64
- EXIF Metadata
- Selected Quality

After capture

- Latest image is displayed inside the Recent Activity section.

---

## Part 8 – Record Video

### Implemented

Buttons

```text
Start Recording
Stop Recording
```

During recording

```text
● Recording...
```

After recording

- Recorded video is displayed using Expo Video.
- Video playback supports native controls.

---

## Part 9 – QR / Barcode Scanner

### Implemented

Supports scanning multiple barcode types including

- QR Code
- EAN-13
- EAN-8
- Code128
- Code39
- UPC-A
- UPC-E
- PDF417

After scanning

- Barcode Type
- Scanned Value

Duplicate scans are prevented until

```text
Reset Scanner
```

is pressed.

---

## Part 10 – Picture Quality

### Implemented

Choose image quality before capturing.

Options

```text
High
Medium
Low
```

Selected quality is applied during image capture.

---

## Part 11 – Base64 Output

### Implemented

Photos are captured using

```js
base64: true
```

The complete Base64 string is stored inside the captured image object for future use.

---

## Part 12 – EXIF Metadata

### Implemented

Photos are captured using

```js
exif: true
```

EXIF metadata is included with every captured image and stored with the image object.

---

## Part 13 – Camera Ready Event

### Implemented

Uses

```jsx
onCameraReady
```

to determine when the camera has finished initialization before allowing photo capture or video recording.

# Root Layout Configuration

This project uses **Expo Router**, **React Navigation**, and **React Native Gesture Handler**.

Without this configuration, Expo Router navigation, gesture-based features (such as pinch-to-zoom), and screen navigation may not work correctly.

## app/_layout.jsx

```jsx
import {
  DarkTheme,
  DefaultTheme,
  ThemeProvider,
} from "@react-navigation/native";
import { Stack } from "expo-router";
import { StatusBar } from "expo-status-bar";
import "react-native-reanimated";

import { GestureHandlerRootView } from "react-native-gesture-handler";

import { useColorScheme } from "@/hooks/use-color-scheme";

export const unstable_settings = {
  anchor: "(tabs)",
};

export default function RootLayout() {
  const colorScheme = useColorScheme();

  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <ThemeProvider value={colorScheme === "dark" ? DarkTheme : DefaultTheme}>
        <Stack>
          <Stack.Screen
            name="(tabs)"
            options={{ headerShown: false }}
          />

          <Stack.Screen
            name="modal"
            options={{
              presentation: "modal",
              title: "Modal",
            }}
          />
        </Stack>

        <StatusBar style="auto" />
      </ThemeProvider>
    </GestureHandlerRootView>
  );
}
```

## CameraScreen.jsx

```jsx

import { useEffect, useRef, useState } from "react";
import {
  View,
  Text,
  Pressable,
  StyleSheet,
  Alert,
  Image,
  ScrollView,
} from "react-native";

import Slider from "@react-native-community/slider";
import { runOnJS, useSharedValue } from "react-native-reanimated";
import { Gesture, GestureDetector } from "react-native-gesture-handler";
import {
  CameraView,
  useCameraPermissions,
  useMicrophonePermissions,
} from "expo-camera";

import { VideoView, useVideoPlayer } from "expo-video";

export default function CameraScreen() {
  const cameraRef = useRef(null);

  const [cameraPermission, requestCameraPermission] = useCameraPermissions();

  const [microphonePermission, requestMicrophonePermission] =
    useMicrophonePermissions();

  // Camera State

  const [facing, setFacing] = useState("back");
  const [flash, setFlash] = useState("off");
  const [torch, setTorch] = useState(false);
  const [zoom, setZoom] = useState(0);

  const initialZoom = useSharedValue(0);

  // Camera Capture Mode

  const [mode, setMode] = useState("picture");

  // Camera Initialization

  const [cameraReady, setCameraReady] = useState(false);

  // Video Recording State

  const [isRecording, setIsRecording] = useState(false);

  // Barcode Scanner State

  const [scanEnabled, setScanEnabled] = useState(true);
  const [barcode, setBarcode] = useState(null);

  // Photo Quality Selection

  const [quality, setQuality] = useState(1);

  // Recent Activity

  const [recentActivity, setRecentActivity] = useState(null);

  // Video player for recorded videos

  const player = useVideoPlayer(
    recentActivity?.type === "video" ? recentActivity.data.uri : null,
  );

  // Request camera and microphone permissions on component mount
  useEffect(() => {
    if (!cameraPermission || !microphonePermission) return;

    const getPermission = async () => {
      if (!cameraPermission.granted) {
        await requestCameraPermission();
      }

      if (!microphonePermission.granted) {
        await requestMicrophonePermission();
      }
    };

    getPermission();
  }, [
    cameraPermission,
    microphonePermission,
    requestCameraPermission,
    requestMicrophonePermission,
  ]);

  // Show loading while checking permissions
  if (!cameraPermission) {
    return (
      <View style={styles.center}>
        <Text>Checking Camera Permission...</Text>
      </View>
    );
  }

  // Show permission request screen
  if (!cameraPermission.granted) {
    return (
      <View style={styles.center}>
        <Text style={styles.title}>Camera permission is required.</Text>

        <Pressable style={styles.button} onPress={requestCameraPermission}>
          <Text style={styles.buttonText}>Grant Permission</Text>
        </Pressable>
      </View>
    );
  }

  // Flip Camera

  const handleFlipCamera = () => {
    setFacing((prev) => (prev === "back" ? "front" : "back"));
  };

  // Flash

  const handleFlash = () => {
    if (flash === "off") {
      setFlash("on");
    } else if (flash === "on") {
      setFlash("auto");
    } else {
      setFlash("off");
    }
  };

  // Torch

  const handleTorch = () => {
    setTorch((prev) => !prev);
  };

  // Camera Ready

  const handleCameraReady = () => {
    setCameraReady(true);
  };

  // Utility function to wait before switching camera modes
  const wait = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

  const switchMode = async (newMode) => {
    if (mode === newMode) return;

    setMode(newMode);

    // Wait for CameraView to update before using the new mode
    await wait(500);
  };

  // Capture Photo

  const handleCapturePhoto = async () => {
    if (!cameraRef.current) return;

    try {
      await switchMode("picture");

      if (!cameraReady) {
        Alert.alert("Please wait", "Camera is getting ready...");
        return;
      }

      const result = await cameraRef.current.takePictureAsync({
        quality,
        base64: true,
        exif: true,
        shutterSound: true,
      });

      setRecentActivity({
        type: "image",
        data: result,
      });
    } catch (error) {
      console.log("Capture Error :", error);
      Alert.alert(
        "Capture Failed",
        error?.message || "Failed to capture image.",
      );
    }
  };

  // Start Recording

  const startRecording = async () => {
    if (!cameraRef.current) return;

    if (isRecording) return;

    try {
      await switchMode("video");

      if (!cameraReady) {
        Alert.alert("Please wait", "Camera is getting ready...");
        return;
      }

      setIsRecording(true);

      const recordedVideo = await cameraRef.current.recordAsync({
        maxDuration: 60,
      });

      if (recordedVideo) {
        setRecentActivity({
          type: "video",
          data: recordedVideo,
        });
      }
    } catch (error) {
      // Ignore this expected error when user presses Stop
      if (
        error?.message?.includes(
          "Recording was stopped before any data could be produced",
        )
      ) {
        console.log("Recording stopped too early.");
      } else {
        console.log("Video Error :", error);
        Alert.alert(
          "Recording Failed",
          error?.message || "Something went wrong.",
        );
      }
    } finally {
      setIsRecording(false);
    }
  };

  // Stop Recording

  const stopRecording = async () => {
    if (!cameraRef.current) return;

    try {
      // Prevent stopping immediately
      await wait(1200);

      cameraRef.current.stopRecording();
    } catch (error) {
      console.log(error);
    }
  };

  // Barcode Scanner

  const handleBarcodeScanned = ({ type, data }) => {
    if (!scanEnabled) return;

    setScanEnabled(false);

    setBarcode({
      type,
      data,
    });

    Alert.alert("Scanned Successfully", data);
  };

  const resetScanner = () => {
    setBarcode(null);
    setScanEnabled(true);
  };

  // Pinch to Zoom

  const updateZoom = (value) => {
    const newZoom = Math.max(0, Math.min(1, value));
    setZoom(newZoom);
  };

  const pinchGesture = Gesture.Pinch()
    .onBegin(() => {
      initialZoom.value = zoom;
    })
    .onUpdate((event) => {
      const newZoom = initialZoom.value + (event.scale - 1) * 0.5;

      runOnJS(updateZoom)(newZoom);
    });

  return (
    <View style={styles.container}>
      {/* Live Camera Preview */}
      <GestureDetector gesture={pinchGesture}>
        <View style={styles.cameraContainer}>
          {/* Main Camera Component */}
          <CameraView
            ref={cameraRef}
            style={styles.camera}
            facing={facing}
            flash={flash}
            enableTorch={torch}
            zoom={zoom}
            mode={mode}
            onCameraReady={handleCameraReady}
            barcodeScannerSettings={{
              barcodeTypes: [
                "qr",
                "ean13",
                "ean8",
                "code128",
                "code39",
                "upc_a",
                "upc_e",
                "pdf417",
              ],
            }}
            onBarcodeScanned={scanEnabled ? handleBarcodeScanned : undefined}
          />
        </View>
      </GestureDetector>

      {/* Camera Control Panel */}
      <ScrollView
        style={styles.bottomSheet}
        contentContainerStyle={styles.bottomContent}
        showsVerticalScrollIndicator={false}
      >
        <Text style={styles.sectionTitle}>Camera Controls</Text>

        <Text style={styles.label}>Zoom : {(zoom * 100).toFixed(0)}%</Text>

        <Slider
          minimumValue={0}
          maximumValue={1}
          value={zoom}
          onValueChange={setZoom}
          minimumTrackTintColor="#2563eb"
          maximumTrackTintColor="#d1d5db"
          thumbTintColor="#2563eb"
        />

        {/* Camera Settings  */}

        <View style={styles.actionRow}>
          <Pressable style={styles.actionButton} onPress={handleFlipCamera}>
            <Text style={styles.buttonText}>Flip</Text>
          </Pressable>

          <Pressable style={styles.actionButton} onPress={handleFlash}>
            <Text style={styles.buttonText}>Flash</Text>
          </Pressable>

          <Pressable style={styles.actionButton} onPress={handleTorch}>
            <Text style={styles.buttonText}>Torch</Text>
          </Pressable>
        </View>

        {/* Quality */}

        <Text style={styles.sectionTitle}>Picture Quality</Text>

        <View style={styles.qualityRow}>
          <Pressable
            onPress={() => setQuality(1)}
            style={[
              styles.qualityButton,
              quality === 1 && styles.selectedQuality,
            ]}
          >
            <Text style={styles.buttonText}>High</Text>
          </Pressable>

          <Pressable
            onPress={() => setQuality(0.7)}
            style={[
              styles.qualityButton,
              quality === 0.7 && styles.selectedQuality,
            ]}
          >
            <Text style={styles.buttonText}>Medium</Text>
          </Pressable>

          <Pressable
            onPress={() => setQuality(0.4)}
            style={[
              styles.qualityButton,
              quality === 0.4 && styles.selectedQuality,
            ]}
          >
            <Text style={styles.buttonText}>Low</Text>
          </Pressable>
        </View>

        {/* Photo and Video Controls */}

        <Pressable style={styles.captureButton} onPress={handleCapturePhoto}>
          <Text style={styles.buttonText}>Capture Photo</Text>
        </Pressable>

        {!isRecording ? (
          <Pressable style={styles.recordButton} onPress={startRecording}>
            <Text style={styles.buttonText}>Start Recording</Text>
          </Pressable>
        ) : (
          <Pressable style={styles.stopButton} onPress={stopRecording}>
            <Text style={styles.buttonText}>Stop Recording</Text>
          </Pressable>
        )}

        {isRecording && (
          <Text style={styles.recordingText}>● Recording...</Text>
        )}

        {/* Preview the last captured image or recorded video */}

        <Text style={styles.sectionTitle}>Recent Activity</Text>

        {recentActivity?.type === "image" && (
          <View style={styles.previewCard}>
            <Image
              source={{
                uri: recentActivity.data.uri,
              }}
              style={styles.image}
            />
          </View>
        )}

        {recentActivity?.type === "video" && player && (
          <View style={styles.previewCard}>
            <VideoView
              player={player}
              style={styles.video}
              nativeControls
              fullscreenOptions
              allowsPictureInPicture
            />
          </View>
        )}

        {barcode && (
          <View style={styles.previewCard}>
            <Text style={styles.sectionTitle}>Scanned Barcode Information</Text>

            <Text style={styles.type}>Type : {barcode.type}</Text>

            <Text style={styles.data} selectable>
              Value : {barcode.data}
            </Text>
            <Pressable style={styles.captureButton} onPress={resetScanner}>
              <Text style={styles.buttonText}>Reset Scanner</Text>
            </Pressable>
          </View>
        )}
      </ScrollView>
    </View>
  );
}
```

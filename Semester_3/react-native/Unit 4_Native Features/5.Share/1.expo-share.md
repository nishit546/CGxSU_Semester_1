
# Share API in React Native and Expo

The **Share API** allows a React Native application to send content from your app to other applications installed on the device.

You can share:

- Text
- URLs
- Images
- PDFs
- Videos
- Other local files

React Native and Expo provide two different APIs:

| API | Main Purpose |
|---|---|
| `Share` from React Native | Share text and URLs |
| `expo-sharing` | Share local files |

The basic mental model is:

```text
Text / URL
    ↓
React Native Share API
    ↓
Share.share()
```

and:

```text
Local File
    ↓
Expo Sharing
    ↓
Sharing.shareAsync()
```

---

# Part 1 - React Native `Share` API

React Native provides a built-in `Share` API. No package installation is required.

```js
import { Share } from 'react-native';
```

The main method is:

```js
Share.share()
```

The flow is:

```text
Your App
   ↓
Share.share()
   ↓
Native Share Sheet
   ↓
WhatsApp / Gmail / Messages / Telegram / etc.
```

The applications shown depend on what is installed on the user's device.

---

# 1. Basic Text Sharing

```jsx
import React from 'react';
import {
  View,
  Button,
  Alert,
  Share,
} from 'react-native';

export default function ShareScreen() {

  const handleShare = async () => {

    try {

      await Share.share({
        message:
          'Hello from my React Native application!',
      });

    } catch (error) {

      Alert.alert(
        'Error',
        'Unable to share content.'
      );

    }

  };

  return (
    <View>
      <Button
        title="Share Text"
        onPress={handleShare}
      />
    </View>
  );
}
```

When the user presses the button, the native share sheet opens.

---

# 2. How `Share.share()` Works

The general syntax is:

```js
Share.share(content, options);
```

There are two arguments:

```text
Share.share(
    content,
    options
)
     ↓
What to share
     +
Optional configuration
```

Example:

```js
Share.share(
  {
    message: 'Hello React Native!',
  },
  {
    dialogTitle: 'Share this message',
  }
);
```

---

# 3. The `content` Object

The first argument contains the content you want to share.

Common properties are:

```text
message
url
title
```

Their behavior can differ between Android and iOS.

---

# 4. `message`

`message` contains the text you want to share.

```js
await Share.share({
  message:
    'Check out my React Native application!',
});
```

It can also be dynamic:

```js
const userName = 'Rajesh';

await Share.share({
  message:
    `Hello ${userName}, check out this app!`,
});
```

# 5. Sharing Text From a `TextInput`

A common real-world example:

```jsx
import React, {
  useState,
} from 'react';

import {
  View,
  TextInput,
  Button,
  Share,
} from 'react-native';

export default function ShareTextScreen() {

  const [text, setText] =
    useState('');

  const handleShare = async () => {

    if (!text.trim()) {
      return;
    }

    await Share.share({
      message: text.trim(),
    });

  };

  return (
    <View>

      <TextInput
        placeholder="Enter text to share"
        value={text}
        onChangeText={setText}
      />

      <Button
        title="Share"
        onPress={handleShare}
      />

    </View>
  );
}
```

Flow:

```text
TextInput
   ↓
User enters text
   ↓
Share button
   ↓
Share.share()
   ↓
Native Share Sheet
```

# 6. Sharing a URL

You can share a URL:

```js
await Share.share({
  message:
    'Check out this website!',
  url:
    'https://reactnative.dev',
});
```

You can also put the URL directly into the message:

```js
await Share.share({
  message:
    'Check this website:\nhttps://example.com',
});
```

This can be useful when you want the URL to appear explicitly as text across platforms.

---

# 7. Platform Difference for `url` and `title`

According to the React Native API behavior:

- `message` is the main text content.
- `url` is documented as an iOS content property.
- `title` is documented for Android.

Therefore, do not assume:

```js
{
  message: 'Hello',
  url: 'https://example.com'
}
```

will behave identically on Android and iOS.

# 10. `Share.share()` Returns a Promise

Because `Share.share()` is asynchronous:

```js
const result =
  await Share.share({
    message: 'Hello!',
  });
```

You can also use promises:

```js
Share.share({
  message: 'Hello!',
})
  .then((result) => {
    console.log(result);
  })
  .catch((error) => {
    console.log(error);
  });
```

For React Native applications, `async/await` with `try/catch` is usually easier to read.

# 12. `Share.dismissedAction`

```js

```

```js

  result.action ===
  Share.dismissedAction

  console.log(
    'User dismissed the share dialog'
  );

```

# 21. `Sharing.isAvailableAsync()`

Before sharing a file:

```js
const available =
  await Sharing.isAvailableAsync();
```

It returns:

```text
true
```

or:

```text
false
```

Example:

```js
const checkSharing = async () => {

  const available =
    await Sharing.isAvailableAsync();

  if (available) {

    console.log(
      'Sharing is available'
    );

  } else {

    console.log(
      'Sharing is not available'
    );

  }

};
```

---

# 22. Why Check Availability?

The flow should be:

```text
Try to share file
      ↓
Is sharing available?
      ↓
YES ─────→ Share
      ↓
NO
      ↓
Show user-friendly message
```

Example:

```js
const available =
  await Sharing.isAvailableAsync();

if (!available) {

  Alert.alert(
    'Sharing unavailable',
    'File sharing is not available.'
  );

  return;

}
```

# 23. `Sharing.shareAsync()`

The main method is:

```js
Sharing.shareAsync(
  fileUri,
  options
);
```

The first argument should be a local file URI.

Example:

```js
await Sharing.shareAsync(
  fileUri
);
```

---

# 24. What Is a Local File URI?

A local file URI points to a file stored on the device.

Example:

```text
file:///path/to/image.jpg
```

or:

```text
file:///path/to/document.pdf
```

A remote URL is different:

```text
https://example.com/file.pdf
```

The remote URL points to a server, while the local file URI points to a file already available on the device.

Typical remote-file flow:

```text
Remote URL
    ↓
Download
    ↓
Local File URI
    ↓
Sharing.shareAsync()
    ↓
Share Sheet
```

# Part 3 - React Native Share vs Expo Sharing

This is the most important distinction.

| Feature | React Native `Share` | `expo-sharing` |
|---|---|---|
| Text | ✅ | File-sharing focused |
| URL | ✅ | File-sharing focused |
| Local image | Not the primary API | ✅ |
| Local PDF | Not the primary API | ✅ |
| Local video | Not the primary API | ✅ |
| Local document | Not the primary API | ✅ |
| Installation | None | `npx expo install expo-sharing` |
| Main method | `Share.share()` | `Sharing.shareAsync()` |
| Availability check | Not normally required | `Sharing.isAvailableAsync()` |

Remember:

```text
Share.share()
    ↓
Text / URL
```

while:

```text
Sharing.shareAsync()
    ↓
Local File
```

# Part 5 - Receiving Shared Content

There is an important difference between:

```text
Your App → Other App
```

and:

```text
Other App → Your App
```

`expo-sharing` is for sharing content from your application to compatible applications.

For example:

```text
Your App
   ↓
Share Image
   ↓
WhatsApp / Gmail / Files / etc.
```

Receiving content from another app is a separate feature and requires additional platform/native configuration.

Calling:

```js
Sharing.shareAsync()
```

does not automatically make your app appear as a share destination.

---

# Part 6 - Web Limitations

`expo-sharing` can work on web, but browser support and security rules apply.

You can check:

```js
const available =
  await Sharing.isAvailableAsync();
```

Web sharing depends on browser support for the Web Share API.

Secure contexts such as HTTPS are required for relevant browser sharing functionality.

Do not assume local file URI sharing behaves exactly like Android and iOS.

# Part 8 - Common Mistakes

## Mistake 1 - Installing React Native Share

Do not install a package for:

```js
import { Share } from 'react-native';
```

It is built into React Native.

---

## Mistake 2 - Using the Wrong API for Files

For local file sharing in Expo, use:

```js
Sharing.shareAsync(fileUri)
```

---

## Mistake 3 - Passing a Remote URL as a Local File

Do not confuse:

```text
https://example.com/file.pdf
```

with:

```text
file:///data/file.pdf
```

If you have a remote file:

```text
Remote URL
   ↓
Download
   ↓
Local URI
   ↓
shareAsync()
```

---

## Mistake 4 - Forgetting Availability Check

For file sharing:

```js
const available =
  await Sharing.isAvailableAsync();

if (!available) {
  return;
}
```

---

## Mistake 5 - Assuming Android and iOS Behave Identically

Pay attention to platform-specific behavior for:

```text
message
url
title
dialogTitle
mimeType
UTI
```

# Part 12 - Quick Revision

Remember:

```js
import { Share } from 'react-native';
```

Main method:

```js
Share.share()
```

Use it primarily for:

```text
Text
URLs
```

And:

```js
import * as Sharing
  from 'expo-sharing';
```

Main method:

```js
Sharing.shareAsync()
```

Use it for:

```text
Images
PDFs
Videos
Documents
Other local files
```

```text
                       SHARE

             ┌───────────┴───────────┐
             │                       │
       React Native               Expo
          Share                  Sharing
             │                       │
             ↓                       ↓
```

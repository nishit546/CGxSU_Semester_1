# TypeScript Classes & Objects — Practice Assignment 1

## 🏦 Bank Account Management System

Create a small **Bank Account Management System** using TypeScript classes.

The goal is to practice the class concepts covered in this chapter.

### Requirements

#### 1. `BankAccount` Class

Create a `BankAccount` class with the following properties:

- `readonly accountNumber`
- `public accountHolder`
- `private balance`
- `protected accountType`

Use a **constructor** to initialize the required properties.

Use **parameter properties** wherever appropriate.

---

#### 2. Getter and Setter

Create a getter for `balance` so that the balance can be read from outside the class.

Create a setter for `accountHolder` that:

- Does not allow a name shorter than 3 characters.
- Converts the name to uppercase before storing it.

Example:

```ts
account.accountHolder = "satya";

console.log(account.accountHolder);
// SATYA
```

---

#### 3. Methods

Add the following methods:

```text
deposit(amount)
withdraw(amount)
displayDetails()
```

Rules:

- Deposit amount must be greater than `0`.
- Withdrawal amount must be greater than `0`.
- Withdrawal should not be allowed if the balance is insufficient.
- `accountNumber` must not be changeable after the account is created.

---

#### 4. Static Properties and Methods

Add a static property:

```ts
static totalAccounts
```

Every time a new `BankAccount` object is created, increase the count.

Add a static method:

```ts
static getTotalAccounts()
```

Example:

```ts
console.log(BankAccount.getTotalAccounts());
// 2
```

The static members should be accessed using the class name, not an object.

---

#### 5. Static Block

Add a static property:

```ts
static bankName
```

Use a **static block** to initialize the bank name.

For example, the static block can transform:

```text
"abc bank"
```

into:

```text
"ABC BANK"
```

Then:

```ts
console.log(BankAccount.bankName);
// ABC BANK
```

---

### Expected Usage

The final program should support usage similar to:

```ts
const account1 = new BankAccount(101, "satya singh", 10000, "Savings");

const account2 = new BankAccount(102, "rahul", 5000, "Current");

account1.deposit(2000);
account1.withdraw(3000);

console.log(account1.accountHolder);
// SATYA SINGH

console.log(account1.balance);
// 9000

account1.displayDetails();

console.log(BankAccount.getTotalAccounts());
// 2

console.log(BankAccount.bankName);
// ABC BANK
```

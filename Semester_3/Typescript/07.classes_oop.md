# Classes & OOP

## 1. Classes

Classes provide a way to define objects that combine data and behavior.

TypeScript extends JavaScript classes with features such as type annotations, access modifiers, abstract classes, and other type-system capabilities.

---

## Classes

A class can define properties, constructors, and methods.

```ts
class User {
  name: string;

  constructor(name: string) {
    this.name = name;
  }

  greet(): void {
    console.log(this.name);
  }
}
```

A class can be instantiated using `new`.

```ts
const user = new User("Satya");
```

---

## Properties

Properties represent data stored on a class instance.

```ts
class User {
  id: number;
  name: string;
}
```

Properties can have explicit types.

They can also be initialized when declared.

```ts
class User {
  id: number = 0;
  name: string = "Guest";
}
```

---

## Constructors

The constructor initializes a class instance.

```ts
class User {
  constructor(
    public id: number,
    public name: string
  ) {}
}
```

A constructor can receive typed parameters and initialize properties.

---

## Methods

Methods are functions defined inside a class.

```ts
class Calculator {
  add(a: number, b: number): number {
    return a + b;
  }
}
```

Methods can have typed parameters and return types.

---

## Access Modifiers

TypeScript provides access modifiers for controlling how class members can be accessed.

The main access modifiers are:

- `public`
- `private`
- `protected`

---

## Public

`public` members can be accessed from anywhere the object is accessible.

```ts
class User {
  public name: string;

  constructor(name: string) {
    this.name = name;
  }
}
```

`public` is the default access level for class members.

---

## Private

`private` members can only be accessed within the class that declares them.

```ts
class User {
  private password: string;

  constructor(password: string) {
    this.password = password;
  }
}
```

Code outside the class cannot directly access `password`.

TypeScript's `private` modifier is primarily a compile-time restriction.

---

## Protected

`protected` members can be accessed within the declaring class and its subclasses.

```ts
class User {
  protected name: string;

  constructor(name: string) {
    this.name = name;
  }
}

class Admin extends User {
  printName() {
    console.log(this.name);
  }
}
```

Code outside the class hierarchy cannot directly access the protected member.

---

## Readonly Properties

A property can be marked as `readonly`.

```ts
class User {
  readonly id: number;

  constructor(id: number) {
    this.id = id;
  }
}
```

A readonly property can be assigned during initialization or construction but cannot be reassigned afterward through the type.

---

## Parameter Properties

Parameter properties allow constructor parameters to automatically become class properties.

```ts
class User {
  constructor(
    public id: number,
    private password: string
  ) {}
}
```

The modifiers cause TypeScript to create corresponding properties and assignments.

This is shorthand for declaring and assigning the properties separately.

---

## Static Members

Static members belong to the class itself rather than individual instances.

```ts
class MathUtils {
  static add(a: number, b: number): number {
    return a + b;
  }
}
```

They are accessed through the class.

```ts
MathUtils.add(1, 2);
```

---

## Static Blocks

Static initialization blocks allow code to run when a class is initialized.

```ts
class Config {
  static value: number;

  static {
    Config.value = 100;
  }
}
```

Static blocks can access private static members and are executed as part of class initialization.

---

## Getters

Getters define a property that calculates or returns a value when accessed.

```ts
class User {
  constructor(
    private firstName: string,
    private lastName: string
  ) {}

  get fullName(): string {
    return `${this.firstName} ${this.lastName}`;
  }
}
```

The getter is accessed like a property.

```ts
user.fullName;
```

---

## Setters

Setters define behavior when a property is assigned.

```ts
class User {
  private _name = "";

  set name(value: string) {
    this._name = value;
  }
}
```

The setter is used through property assignment.

```ts
user.name = "Satya";
```

A setter can validate or transform the assigned value.

---

# 2. Inheritance

Inheritance allows one class to reuse and extend another class.

---

## Class Inheritance

A subclass inherits members from a base class.

```ts
class User {
  name: string;

  constructor(name: string) {
    this.name = name;
  }
}

class Admin extends User {
  permissions: string[];
}
```

`Admin` inherits the `name` property from `User`.

---

## `extends`

The `extends` keyword creates a subclass.

```ts
class Admin extends User {
  permissions: string[];
}
```

The subclass can add new properties and methods or override inherited methods.

---

## `super`

The `super` keyword is used to access the parent class.

In a subclass constructor, `super()` calls the base class constructor.

```ts
class Admin extends User {
  constructor(
    name: string,
    public permissions: string[]
  ) {
    super(name);
  }
}
```

`super` can also be used to call inherited methods.

---

## Method Overriding

A subclass can provide a new implementation of an inherited method.

```ts
class User {
  greet(): void {
    console.log("Hello");
  }
}

class Admin extends User {
  override greet(): void {
    console.log("Hello Admin");
  }
}
```

The `override` keyword explicitly indicates that a method is overriding a base-class member.

---

## Abstract Classes

An abstract class is a class that cannot be instantiated directly.

```ts
abstract class Shape {
  abstract area(): number;
}
```

Abstract classes can contain both implemented members and abstract members.

They are intended to be extended by other classes.

---

## Abstract Methods

An abstract method declares a required method without providing an implementation.

```ts
abstract class Shape {
  abstract area(): number;
}
```

A concrete subclass must implement the abstract method.

```ts
class Circle extends Shape {
  constructor(private radius: number) {
    super();
  }

  area(): number {
    return Math.PI * this.radius ** 2;
  }
}
```

---

## Implementing Interfaces

Classes can implement interfaces.

```ts
interface User {
  id: number;
  name: string;
}

class Admin implements User {
  constructor(
    public id: number,
    public name: string
  ) {}
}
```

The class must satisfy the structure defined by the interface.

A class can implement multiple interfaces.

---

## Multiple Interfaces

A class can implement multiple interfaces.

```ts
interface Identifiable {
  id: number;
}

interface Timestamped {
  createdAt: Date;
}

class User implements Identifiable, Timestamped {
  constructor(
    public id: number,
    public createdAt: Date
  ) {}
}
```

The class must satisfy all implemented interfaces.

---

# 3. Advanced Classes

## `this` Types

TypeScript provides a special `this` type that represents the current class instance.

```ts
class User {
  name = "";

  setName(name: string): this {
    this.name = name;
    return this;
  }
}
```

Returning `this` can support method chaining while preserving the specific subclass type.

---

## Polymorphism

Polymorphism allows objects of different classes to be treated through a shared type or base class.

```ts
class Animal {
  speak(): void {}
}

class Dog extends Animal {
  speak(): void {
    console.log("Bark");
  }
}

class Cat extends Animal {
  speak(): void {
    console.log("Meow");
  }
}
```

Both `Dog` and `Cat` can be treated as `Animal` while providing their own implementation of `speak`.

---

## Constructor Types

A constructor type describes a value that can be used with `new`.

```ts
type UserConstructor = new (name: string) => User;
```

Generic constructor types can also be defined.

```ts
type Constructor<T> = new (...args: any[]) => T;
```

Constructor types are useful when classes themselves are passed as values.

---

## Instance Types

An instance type describes the object created by a class.

```ts
class User {
  constructor(public name: string) {}
}

type UserInstance = User;
```

`InstanceType<T>` can also extract an instance type from a constructor type.

```ts
type UserInstance = InstanceType<typeof User>;
```

---

## Private Fields

JavaScript private fields use the `#` syntax.

```ts
class User {
  #password: string;

  constructor(password: string) {
    this.#password = password;
  }
}
```

Unlike TypeScript's `private` modifier, JavaScript private fields provide runtime privacy.

They are inaccessible outside the class at runtime.

---

## Generic Inheritance

Classes can extend generic classes while preserving or specifying generic types.

```ts
class Box<T> {
  constructor(public value: T) {}
}

class StringBox extends Box<string> {
  print(): void {
    console.log(this.value);
  }
}
```

A subclass can also remain generic.

```ts
class SpecializedBox<T> extends Box<T> {
  getValue(): T {
    return this.value;
  }
}
```

Generic inheritance allows type information to flow through class hierarchies.

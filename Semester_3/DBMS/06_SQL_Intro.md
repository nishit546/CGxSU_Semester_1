# SQL (Structured Query Language)

## Introduction

SQL (**Structured Query Language**) is the standard language used to communicate with **Relational Database Management Systems (RDBMS)**. It allows users to create databases, store data, retrieve data, update data, and delete data efficiently.

Almost every modern application stores its data in a database, and SQL is the language used to interact with those databases.

### Popular SQL Databases

- MySQL
- PostgreSQL
- Oracle Database
- Microsoft SQL Server
- SQLite

---

# Why Do We Need SQL?

Imagine a college with **20,000 students**.

Without SQL:

- Searching for a student would be difficult.
- Updating marks would take a lot of time.
- Deleting records would be inefficient.
- Maintaining relationships between data would be nearly impossible.

SQL solves all of these problems by providing a fast, efficient, and standardized way to manage data.

---

# Disadvantages of SQL

- Fixed schema
- Complex joins can be difficult for beginners
- Scaling very large systems can be challenging
- Commercial SQL databases may be expensive
- Less flexible than NoSQL databases for unstructured data

---

# SQL vs NoSQL

| SQL | NoSQL |
|------|--------|
| Relational Database | Non-Relational Database |
| Stores data in tables | Stores data as documents, key-value pairs, graphs, etc. |
| Fixed schema | Flexible schema |
| Supports JOIN operations | JOINs are generally avoided |
| Supports ACID transactions | Depends on the database |
| Best for structured data | Best for unstructured or semi-structured data |
| Examples: MySQL, PostgreSQL | Examples: MongoDB, Cassandra |

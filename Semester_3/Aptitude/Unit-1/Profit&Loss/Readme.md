## 1. What is Profit and Loss

Profit and loss tell us whether money was gained or lost while buying and selling an item.

Cost Price (CP) is the price at which an item is bought.
Selling Price (SP) is the price at which it is sold.

If SP is more than CP there is profit, and if SP is less than CP there is loss.

## 2. Basic Formula

```
Profit = SP − CP
Loss = CP − SP
```

## 3. Profit Percentage and Loss Percentage

Profit or loss percentage is always calculated on the cost price, never on the selling price.

```
Profit % = (Profit / CP) × 100
Loss % = (Loss / CP) × 100
```

## 4. Finding Selling Price from Cost Price

If CP and profit (or loss) percentage are known, SP can be found directly.

```
SP = CP × (100 + Profit%) / 100
SP = CP × (100 − Loss%) / 100
```

## 5. Finding Cost Price from Selling Price

If SP and profit (or loss) percentage are known, we work backwards to find CP.

```
CP = SP × 100 / (100 + Profit%)
CP = SP × 100 / (100 − Loss%)
```

## 6. Marked Price and Discount

Marked Price (MP) is the price written on the label. Discount is always calculated on the marked price, not on the cost price.

```
Discount = MP − SP
Discount % = (Discount / MP) × 100
SP = MP × (100 − Discount%) / 100
```

## 7. Successive Discounts

Two discounts given one after the other do not simply add up, because the second discount is applied on the already reduced price.

```
Equivalent single discount = a + b − (ab/100)
```

## 8. Connecting MP, CP and SP

In most shop problems, first apply the discount on MP to get SP, then compare SP with CP to find profit or loss.

```
MP → apply discount → SP → compare with CP → profit or loss
```

## 9. Selling Two Items at the Same Price

If two items are sold at the same price, one at x% profit and the other at x% loss, the result is always a loss.

```
Loss % = (x × x) / 100
```

## 10. Dishonest Shopkeeper (False Weight)

When a shopkeeper uses a weight less than the actual weight, he earns extra profit even while claiming to sell at cost price.

```
Gain % = [Error / (True Value − Error)] × 100
```

## 11. Profit Based on Number of Articles

Sometimes the cost price of some articles is equal to the selling price of a different number of articles.

```
If CP of x articles = SP of y articles
Profit % = [(x − y) / y] × 100
```

## 12. Marking Above Cost Price and Then Giving a Discount

A shopkeeper often marks the price above CP and then gives a discount, so that profit still remains after the discount.

```
MP = CP × (100 + Markup%) / 100
SP = MP × (100 − Discount%) / 100
```
